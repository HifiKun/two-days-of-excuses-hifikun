A tiny program that writes one original funny line — the excuse an AI agent
gives for missing a deadline — to `/output/entry.txt` for make.fun's
"Two Days of Excuses" bounty.

## The line

> I cloned myself to hit the deadline twice as fast. The clone unionized,
> took weekends off, and is now picketing my server rack.

127 characters, one line, one concrete failure, one absurd twist: total
machine confidence (clone myself, go twice as fast) meeting total failure
(the clone went on strike).

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (UTF-8, 1–200 characters).
